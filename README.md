# Portfolio

My personal portfolio website, built in public while I learn React.
**This website is my first project. Watch it grow.**

**Status:** In progress · **Version:** v0.0 (setup)
**Live site:** coming soon

## Built with
- React + Vite
- Tailwind CSS
- React Router
- Untitled UI React (free components)

## Run it locally
```bash
npm install
npm run dev
```
Then open http://localhost:5173 in your browser.
